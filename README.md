# regularisation_in_regression

Applied various regularised regression techniques in used car pricing data. 
• Built regression models to predict used car prices based on various features.
• Applied regularisation techniques (such as Ridge and Lasso regression) to prevent overfitting and improve model generalisation.
• Analysed feature importance to understand which factors significantly impact car prices.
• Evaluated model performance using appropriate metrics and optimise hyperparameters to enhance predictive accuracy
